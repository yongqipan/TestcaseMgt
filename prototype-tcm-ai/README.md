# TCM 测试管理 · AI 深度集成原型

在现有 TCM 测试管理系统基础上深度集成 AI 能力的高保真交互原型，纯静态 HTML/CSS/JS，无构建、无依赖。

## 打开方式

直接双击 `index.html`，或在目录内启动静态服务：

```bash
# 启动本地静态服务（端口 5181）
python3 -m http.server 5181
```

浏览器访问 http://localhost:5181 。

## 设计原则落地

- AI 输出仅供参考：所有生成与评审结果均需人工逐条确认后才写入用例库，页面显式提示低置信度用例建议复核。
- AI 不阻塞主流程：模型服务状态、熔断降级与配额在侧栏和 AI 平台页显式呈现，测试用例与计划链路可独立完成。
- 结果可溯源：每次生成/评审/报告都能在调用日志中按场景、模型、Token、耗时追溯。
- 多模型可配置：默认模型、场景路由（生成/评审/嵌入）、备用模型降级策略均可在模型设置中调整。

## AI 停靠面板

- 右侧常驻「TCM AI 助手」抽屉，主内容自动让位。
- 抽屉边缘的三角按钮可收起/展开；收起后主内容占满宽度。
- 快捷指令：生成用例 / 质量评审 / 失败根因 / 生成报告，回复按关键词变化并提供跳转按钮。
- 支持输入框回车发送、Shift+回车换行、拖拽或点 ＋ 上传需求/接口文档，上传后 AI 解析出可测试点。
- ⟳ 清空对话。
- 桌面端（>980px）默认展开；≤980px 默认收起，展开时带遮罩；≤560px 抽屉占满屏宽。

## 交互提示

- 用例列表点击任意行弹出详情，详情内可一键跳转 AI 评审。
- AI 生成用例页的开关可逐条勾选，「写入用例库」按选中数量提示。
- 模型设置页「测试连接」「保存配置」「熔断降级」均可交互。
- Prompt 模板点击「编辑」打开模板编辑弹窗。
- 窄屏（≤980px）左上是汉堡菜单，点击展开侧栏。

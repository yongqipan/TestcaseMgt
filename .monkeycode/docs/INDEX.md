# 测试用例管理系统 文档

## 项目概述

测试用例管理系统（Test Case Management，简称 TCM）是一个前后端分离的 Web 应用，用于集中管理软件测试资产与执行过程。系统以项目为边界组织模块、测试用例与测试计划，并记录每一次用例执行结果，为测试团队提供可追溯的质量数据。

**目标用户**：测试工程师、测试负责人、研发工程师

**核心价值**：
- 以项目/模块树结构化沉淀测试用例，避免用例散落在文档中
- 通过测试计划组织本轮测试范围，并逐条记录执行结果
- 以仪表盘呈现用例覆盖率、通过率与缺陷分布，支撑质量决策

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 后端语言 | Java 17 | 长期支持版本，环境提供 OpenJDK 17 |
| 后端框架 | Spring Boot 3.2.5 | 快速构建 REST API，生态成熟 |
| 持久层 | Spring Data JPA (Hibernate) | 简化 CRUD 与分页查询 |
| 数据库 | MySQL 8.0.46 | 用户指定版本，utf8mb4 支持中文 |
| 前端框架 | Vue 3 + Vite | 组合式 API，开发体验好 |
| UI 组件 | Element Plus | 企业级中后台组件库 |
| 状态管理 | Pinia | 轻量、类型友好 |
| HTTP 客户端 | Axios | 拦截器统一处理令牌与错误 |
| 认证 | Token + BCrypt | 无状态令牌，密码加盐哈希存储 |

## 核心功能

### 认证与用户
- **目的**：限制系统访问范围
- **描述**：账号密码登录，签发访问令牌；令牌过期后需重新登录

### 项目管理
- **目的**：以项目隔离测试资产
- **描述**：项目的新增、编辑、删除、关键字检索与分页浏览

### 模块管理
- **目的**：按业务域组织测试用例
- **描述**：项目内维护多级模块树，支持新增、重命名、删除

### 测试用例管理
- **目的**：沉淀可复用的测试用例
- **描述**：维护标题、编号、优先级、类型、状态、前置条件与测试步骤；支持按项目、模块、关键字、优先级、状态筛选

### 测试计划与执行
- **目的**：组织一轮测试并记录结果
- **描述**：创建计划并关联项目全部用例，逐条标记通过/失败/阻塞/跳过，实时统计通过率

### 仪表盘
- **目的**：概览质量数据
- **描述**：统计项目数、用例数、计划数、执行数、通过率、优先级与状态分布
